User System API 

 

DOCUMENT PURPOSE: 

The purpose of this API is to provide a unified user data management interface that supports CRUD operations for enterprise applications. It enables system components to access and manage user information with persistent storage in a relational database.

POST /api/v1/users - Create a new user 

POST /api/v1/users — Create a new user 

Security: users:write 
Required headers: 

Authorization: Bearer <token> 

Content-Type: application/json; charset=utf-8 

traceparent: <generated or propagated> 
Optional headers: 

tracestate: <vendor-data> 

Idempotency-Key: <uuid> (prevents duplicate creates on retries) 

Request body 

JSON 

{ 

"email": "jane.doe@example.com", (M) 

"phone": "+1-555-0100", (M) 

"firstName": "Jane", (M) 

"lastName": "Doe", (M) 

"address": "" (O)  

} 

Sample request (curl) 

Shell 

curl -X POST "https://api.example.com/user-sys-api/api/v1/users" \ 

-H "Authorization: Bearer <token>" \ 

-H "Content-Type: application/json" \ 

-H "traceparent: 00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01" \ 

-H "Idempotency-Key: 0d1c7f7e-6b0f-4c0a-8d6c-2dd7a3c5a111" \ 

-d '{"email":"jane.doe@example.com","phone":"+1-555-0100","firstName":"Jane","lastName":"Doe"}' 

Responses 

201 Created 
Headers: 

Location: /user-sys-api/api/v1/users/usr_123 

ETag: "v1" 
Body: 

JSON 

{ 

"id": "usr_123", 

"email": "jane.doe@example.com", 

"status": "ACTIVE", 

"createdAt": "2025-09-05T08:07:00Z", 

"updatedAt": "2025-09-05T08:07:00Z", 

"version": 1 

} 

202 Accepted (rare; if creation is async) 

Errors: 400 (validation), 401, 403 (scope), 409 (duplicate email), 422, 429, 500 

Notes 

Use Idempotency-Key to make repeated POSTs safe. 

Emit user.created event (include traceId).
